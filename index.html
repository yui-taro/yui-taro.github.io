      作品の核を、一文にしてから作る

      「戦い方が、そのまま料理の出来になる」のように、何を体験してもらう作品なのかを一文で言えるまで企画を詰めてから、設計に入るようにしています。

      AIエージェントと分担して開発する

      企画書・設計書の作成から実装、自動テストまで、Claude Code に任せる範囲と自分で判断する範囲の分け方を試しながら進めています。

    3. 03

      遊べる形で公開し、感想から直す

      ブラウザ版や配布ページを用意して実際に遊んでもらい、そこで見つかった問題を次の改善につなげています。
